# センサーの書き方

このフォルダには、センサー1つにつき1ファイルを置きます。各ファイルには、値を測って返す関数 `read()` を1つだけ書きます。
値の保存・判定・通知はほかの担当が作るので、センサー担当が書くのは `read()` と、このREADMEの自分の節だけです。
詳しい約束ごとは、リポジトリのルートにある `水耕栽培センサー管理 技術仕様書.md` の第4・5章を見てください。

## read() の約束

- 測った値を、次の形の辞書のリストで返す。1つのセンサーで2つ以上の値を測るときは、リストに並べる。

  ```python
  [{"metric": "air_temp", "label": "気温", "value": 21.3, "unit": "℃"}]
  ```

- 読めなかったら例外を投げる。0 や前回の値で埋めない。
- 1回の読み取りは10秒以内に終える。
- センサー用ライブラリの import は `read()` の中に書く（ラズパイのないPCでも、全体が起動できるように）。
- 計測時刻を付けて保存するのは `collect.py` の役目なので、保存の処理は書かない。

`metric`・`label`・`unit` は、次の表のとおりにそろえます。

| ファイル | センサー | metric | label | unit |
| --- | --- | --- | --- | --- |
| `bme280.py` | BME280 | `air_temp`、`humidity` | 気温、湿度 | ℃、% |
| `bh1750.py` | BH1750 | `light` | 照度 | lx |
| `water_level.py` | アナログ水位センサー＋ADS1115 | `water_level` | 水位 | cm |
| `water_temp.py`（センサー未確保） | DS18B20 | `water_temp` | 液温 | ℃ |
| `ec.py`（センサー未確保） | 未定 | `ec` | EC | mS/cm |

## 動作確認

`bushitsu-dashboard/` で次のように実行すると、自分のセンサーの `read()` だけを動かして結果を表示できます（`bme280` の部分を自分のファイル名に変える）。

```bash
python -m hydroponics.sensors.bme280
```

ひな形のままだと `NotImplementedError` が出ます。

## 一覧への登録

`read()` ができてラズパイで動作確認できたら、`__init__.py` の `PI_SENSORS` に追加します。共用のラズパイに統合するときに、Pi基盤担当と一緒に行います。

## 配線と安全

- 配線を変えるときは、必ずラズパイの電源を切る。
- 5Vの信号をGPIOに直接入れない。センサーの電源は3.3Vにする。
- 使うピンとI2Cアドレスは仕様書の第4章の表で決めている。変えるときはPi基盤担当に相談する。
- 共用のラズパイへの配線は、Pi基盤担当が立ち会う。
